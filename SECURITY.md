# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Antigravity Bridge, please report it privately to the maintainers rather than opening a public issue. We appreciate your efforts to responsibly disclose findings and will work to address verified issues promptly.
